# Pinned RILA Income source family

This folder prepares three exact official Income calculator presets for the
existing native Calculator/SDK catch-all model. It does not create a route,
change native fields or implement another financial formula.

`source-assets.json` pins three different original JavaScript binaries, three
small product stylesheets, the already pinned Lifetime shared stylesheet and
18 existing font files. Three root-relative workbook aliases preserve the
source request paths; ADV and Select Income have the same workbook bytes, while
Plus Income differs. No source script, stylesheet, font or workbook is rewritten.

The static HTML shells start with an inert main region. The parent component
must install the existing local-or-`#` link policy, its pointer/keyboard/auxiliary
capture listeners and mutation observer before enabling that region. A standalone
frame is deliberately inert and is not a functional acceptance fixture.

## What static inspection established

Each app mounts `dx-income-index-advantage`, constructs its local store and makes
one binary-arraybuffer workbook GET. Its Compute handler prevents native form
submission and calculates in the store. An independent complete-bundle AST scan
found no direct browser `open`, location assignment, native `.submit()` or `eval`
call. Each has one `window.print()` call. Bundled unused login/header modules are
not proof that those components execute.

The active results link chooses a legacy strategy-calculator path, with a
precision-exclusion suffix in one case. The parent must contain those destinations
and avoid navigating the outer demo inside the iframe. No generic proxy, network
interceptor, credential, remote financial submission or new package is introduced.

## Provenance and licensing

These are unchanged public Allianz assets, retained for the authorized Allianz
migration. Their original package/version comments remain in the files. The
distributed minified scripts do not contain a complete dependency-license notice
set; this preparation does not assert that public availability establishes a new
license or entitlement. Existing proprietary font bytes are reused rather than
recopied. No package installation or newly licensed financial library was added.

## Offline checks

```sh
node --test examples/allianz-life/src/components/allianz-calculator/rila-income-source/source-assets.test.mjs
```

The tests fence source identity, preset/bootstrap configuration, direct static
workbook resolution, ordinary XLSX parts, font resolution and inert local shell
bootstraps. They do not execute the source apps or establish independent financial
truth.
