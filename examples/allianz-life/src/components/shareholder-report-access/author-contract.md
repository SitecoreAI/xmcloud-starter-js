# Shareholder report access

Two source pages provide a report gateway rather than a document collection. `Default` keeps the modern centered introduction: one **Shareholder reports heading** (`heading`, Single-Line Text) and one **View shareholder reports** (`reportsLink`, General Link). Its arrow, centered structure, empty subheading, and trailing empty row are fixed source presentation.

`NewYork` retains the single source pre-content link-list item. Its page heading remains separate, so this variant uses only `reportsLink`. The sole parameter is `RenderingIdentifier`. No collection, document files, card images, paragraph body, theme, alignment, or heading-level author controls are required by either source page.

Each real field object, including an empty authored field, reaches the SDK unchanged in editing mode. The link's own General Link caption is used. The existing safety adapter continues to make the external Broadridge service unavailable to visitors until the shared verified delivery policy changes. No report files or service responses have been invented.

Actual native template/datasource adoption and external-service acceptance are pending. Exact archived structure, action copy, arrow geometry, and cleared-field editing tests live beside `prospectus-document-table`.
